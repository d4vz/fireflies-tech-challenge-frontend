# fireflies-tech-challenge-frontend

Frontend for the Fireflies challenge.

How to run it is in the [parent README](https://github.com/d4vz/fireflies-tech-challenge). Copy `.env.example` to `.env.local` and fill in the Clerk keys. `API_URL` stays `http://localhost:3000` when the backend compose stack is up. The frontend still runs on the host with Bun.
